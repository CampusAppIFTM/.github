# Canvas do problema

| Canvas do Problema |   |
| --- | --- |
| **Equipe:** |   |
| **1\. Qual é o problema?** Descreva em uma frase o que incomoda, falta ou atrapalha alguém. | A falta de uma rede de apoio estruturada dificulta que estudantes neurodivergentes recebam suporte adequado durante crises e momentos de desregulação emocional. |
| **2\. Quem sofre com isso?** Quem é o usuário? Quantas pessoas? Na escola? Na comunidade? | Os alunos neurodivergentes |
| **3\. Como resolve hoje?** Papel, WhatsApp, memória, planilha? O que existe mas é ruim? | Criar uma plataforma de conversa entre os alunos neurodivergentes e para os membros do CAPNE e para o CAE, para saber quando os alunos estão tendo crises |
| **4\. Por que um app resolve?** O que o celular oferece que a solução atual não tem? | Pois quando existe uma rede de apoio maior, ajuda a conter crises que iriam ficar mais sério e que durariam muito e se tivesse essa plataforma ajudaria para diminuir a intensidade da crise e a duração |
| **5\. Nome do app (provisório):** Pode ser criativo. Será possível mudar depois. | Radar Neuro Divergente |
| **6\. Uma tela em 30 seg:** Descreve verbalmente como seria a tela principal. | A primeira tela seria a de login, iria aparecer a logo e as partes de nome do usuário e a senha. E quando não tem uma conta irá ter um botão de criar conta para o usuário conseguir entrar na plataforma, quando o usuário estiver tendo uma crise terá um botão chamado “Emergência” que ira abrir um chatbot para ir ajudando e assim que clicar enviar uma mensagem para o CAPNE e para o CAE para irem ajudar o estudante. Quando entrar vai ter os seguintes botões: Procurar amizade, Conversar e Modificação de usuário. |
