**Perguntas que a equipe pode usar para preencher o Canvas do problema**

* "Quem vai usar esse app? Você pessoalmente ou alguém que você conhece?"

* "Como essa pessoa resolve o problema hoje, sem o app?"

* "O que acontece se o app não existir? A vida continua? Como?"

* "Em quanto tempo essa pessoa usaria o app? Toda hora? Uma vez por semana?"

* "Se vocês tivessem só uma tela para mostrar, qual seria?"

|  Critério de aprovação do Canvas |
| :---- |
| Uma ideia está pronta para avançar quando o grupo consegue responder verbalmente, em 30 segundos, sem consultar o papel: |
| Quem é o usuário (específico, não 'todo mundo')? |
| Qual dor ou problema ele tem? |
| Por que o celular é a melhor solução? |
| **Se não conseguir responder as três**, o Canvas precisa ser refeito antes do MVP Workshop. |

| Canvas do Problema |  |
| ----- | :---- |
| **Equipe:** |  |
| **1\. Qual é o problema?** Descreva em uma frase o que incomoda, falta ou atrapalha alguém. | Os alunos e responsáveis têm dificuldade para organizar e consultar os horários disponíveis da quadra esportiva, gerando conflitos e falta de controle nos agendamentos.  |
| **2\. Quem sofre com isso?** Quem é o usuário? Quantas pessoas? Na escola? Na comunidade? | Os alunos, professores e responsáveis pela administração da quadra esportiva da escola.Todas as pessoas inseridas nesse meio podem ser afetadas pela falta de organização dos horários.  |
| **3\. Como resolve hoje?** Papel, WhatsApp, memória, planilha? O que existe mas é ruim? | Atualmente, os horários podem ser controlados por grupos de WhatsApp. Esses métodos dificultam a visualização dos horários disponíveis.  |
| **4\. Por que um app resolve?** O que o celular oferece que a solução atual não tem? | O aplicativo permite consultar a programação da quadra em tempo real, visualizar horários disponíveis e realizar agendamentos de forma rápida e organizada pelo celular, reduzindo erros e facilitando o acesso às informações. |
| **5\. Nome do app (provisório):** Pode ser criativo. Será possível mudar depois. | Anbylize |
| **6\. Uma tela em 30 seg:** Descreve verbalmente como seria a tela principal. | A tela principal exibirá um calendário com os horários da quadra. Os horários livres aparecerão em verde e os ocupados em vermelho. Na parte superior haverá a data selecionada e, abaixo, a programação completa do dia. Um botão "Agendar Horário" permitirá que o usuário escolha um horário disponível e faça sua reserva rapidamente. Também haverá uma área para consultar os próximos agendamentos realizados.  |
